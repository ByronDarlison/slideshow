# Presentation fonts

Local web fonts so a deck does not depend on an internet connection.

- `geist-latin.woff2`: Geist Sans, display and body.
- `geist-mono-latin.woff2`: Geist Mono, labels and compact navigation.

[Geist](https://github.com/vercel/geist-font) is SIL Open Font License 1.1.
